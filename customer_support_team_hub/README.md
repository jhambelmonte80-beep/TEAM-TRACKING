# Customer Support Team Hub

A responsive, browser-based team operations dashboard for customer support managers.

## Included modules
- Overview dashboard and quick stats
- Agent profiles and development focus
- One-on-one coaching log and follow-up actions
- Quality assurance reviews and feedback
- Attendance notes and warning records
- Agent shift schedules and coverage notes
- SOP/process library
- Tools and access-status tracker
- Client decisions and escalations
- Reports and CSV export

## Run locally
Open `index.html` in a modern browser. No build tools or installation are required.

## Data and privacy
Entries are stored in the browser's localStorage on the device/browser where the page is opened. This is a front-end demo, not a secure multi-user database. Do not store passwords, payment data, customer personal information, health information, or sensitive employee information. For real team deployment, use an authenticated backend, role-based permissions, audit logs, backups, and an HR-approved process for performance records.

## Customize
- Edit `css/styles.css` for colors and layout.
- Edit `js/app.js` to add fields, workflows, validations, and reporting.
- Edit `index.html` to change navigation and page structure.

All sample dashboard values start empty. Add your own demo or authorized operational records.
